# Teller

Kalorien- und Mahlzeiten-App für Valli (Android).

## ⬇️ [Teller herunterladen (neueste Version)](https://github.com/PPADaniel/teller-app/releases/latest/download/Teller.apk)

### Installieren

1. Den Link oben **auf dem Handy** öffnen – das lädt `Teller.apk` herunter.
2. Die heruntergeladene Datei antippen.
3. Beim ersten Mal fragt Android, ob der Browser Apps installieren darf: **Zulassen**,
   dann zurück und **Installieren**.
4. Falls Google Play Protect warnt: **Weitere Details → Trotzdem installieren**.
   Teller ist nicht im Play Store, darum diese Warnung.

### Updates

Gibt es eine neue Version, zeigt Teller auf **Heute** «Neue Version» an. **Laden und installieren**
tippen, dann bei Android **Aktualisieren** – alle Einträge bleiben erhalten. Beim ersten Mal fragt
Android einmal, ob Teller Apps installieren darf («Apps aus dieser Quelle zulassen»).
Alternativ einfach den Link oben nochmals öffnen.

Alle Versionen: [Releases](https://github.com/PPADaniel/teller-app/releases)
